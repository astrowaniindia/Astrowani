# Astrowani — https://astrowani.com
#
# The Sitemap line below points at a BACKEND ROUTE, not a file in this directory.
# The blog agent publishes three articles a day into the `blogs` table and cannot
# commit to this git-deployed folder, so a static sitemap.xml here would be stale
# within hours. See astrowani-backend/src/blogSitemap.js.
#
# EVERY Disallow HERE MUST BE ABSENT FROM THAT SITEMAP, and vice versa.
# Submitting a URL in a sitemap while blocking it here is a self-inflicted
# Search Console error ("Indexed, though blocked by robots.txt").
#
# ---------------------------------------------------------------------------
# THIS FILE ONLY TAKES EFFECT AT A DOMAIN ROOT.
#
# robots.txt is read from the HOST root and nowhere else. While the site is
# served from shop.astrowani.com/test-site/, a crawler reads
# shop.astrowani.com/robots.txt — a different file entirely — and never sees
# this one, so neither the rules nor the Sitemap line below do anything.
# Verified 2026-10-29. This file starts working the day the site takes
# astrowani.com, and until then the sitemap has to be submitted by hand in
# Search Console.
#
# WHEN THIS SITE MOVES TO astrowani.com: this file replaces the WordPress
# robots.txt generated by the ThinkRank SEO plugin. Its WordPress-only rules
# (/wp-admin/, /xmlrpc.php, /cart/, /checkout/, /my-account/) are deliberately
# NOT carried over — none of those paths exist here, and disallowing a path that
# does not exist only advertises what used to be there.
# ---------------------------------------------------------------------------

User-agent: *
Allow: /

# Per-user pages: behind a login, different for every visitor, nothing to index.
Disallow: /wallet.html

# THE LIVE CONSULTATION SCREENS — not landing pages.
#
# An earlier version of this file said the opposite, in writing: that chat.html
# and call.html "are in fact the 'Chat with an Astrologer' / 'Call an Astrologer'
# landing pages, which carry the highest-intent keywords on the site". That was
# wrong, and the sitemap submitted both on the strength of it.
#
# Their entire text content is "Astrologer / Connecting… / Mute / Camera off /
# End chat / Billing is per minute from now". Neither has an <h1>; chat.html has
# one internal link and call.html has none. Indexed, Google could serve a page
# reading "Connecting…" for the query "chat with an astrologer".
#
# The real landing page for that intent is consult.html — <h1> "Chat with an
# astrologer", 4,200 characters — and it stays in the sitemap at priority 0.8.
# Both pages also carry <meta name="robots" content="noindex, follow"> so this
# holds even where robots.txt is not read.
Disallow: /chat.html
Disallow: /call.html

# A leftover design experiment: reachable, linked from nothing, not in the sitemap.
Disallow: /concept-hero.html

Sitemap: https://backend.astrowani.com/api/blogs/sitemap.xml
